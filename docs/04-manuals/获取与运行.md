# 在另一台电脑获取与运行

## 获取代码

本 PR 基于 `ycccuc/dogfight-threat-ai` 的 `main`，开发分支为 `feat/cinematic-main-menu`。

首次获取仓库：

```sh
git clone https://github.com/ycccuc/dogfight-threat-ai.git
cd dogfight-threat-ai
```

PR #2 合并前，审核者可以取出该 PR 的最新提交：

```sh
git fetch origin pull/2/head:review/menu-map
git switch review/menu-map
```

合并后使用更新后的 `main` 即可。切换代码分支前请先退出编辑器，避免场景和资源导入过程与文件变更冲突。

## 引擎与依赖

- 工程目标保持原仓库的 **Unity 2022.3.62f3c1**，使用 Unity Hub 添加 `src/client/DogfightThreatAI`，不要把仓库根目录当成 Unity 工程。
- 源码、场景、资源及 `.meta`、`Packages` 和 `ProjectSettings` 均通过 Git 获取；`Library`、`Temp`、`Logs`、`UserSettings` 会由编辑器在本机生成，无需从其他电脑复制。
- 初次打开需要联网解析原有 Package Manager 依赖，并安装 Git 以获取工程已有的 Git 包。当前游戏运行不依赖 Python、uv 或 MCP 服务；这些仅供可选的 Unity MCP 开发工具使用。
- 本次功能已在 **团结 2022.3.62t16 / 1.10.4** 验证，包含 18 项 EditMode、5 项 PlayMode 测试及主工程实际界面操作。**尚未在目标 Unity 版本或独立构建包验收**，不将团结的验证结果等同于目标 Unity 验收。
- PR 保留原有引擎版本和依赖配置，不包含本机团结自动升级包、切换包注册表或生成平台设置的改动。如在团结打开，请在单独工作副本内操作并检查其自动修改，避免把本机迁移配置混入功能提交。

## 运行游戏

1. 等待依赖解析、资源导入和脚本编译完成。
2. 打开 `Assets/_Project/Scenes/StartMenu/StartMenu.unity`，或选择 **Tools → Dogfight Threat AI → 打开完整游戏入口**。
3. 点击 Play，看到“点击任意键进入游戏”后按键显示菜单。
4. 点击“开始游戏”，进入 `GameScene` 的河谷农田地图。飞机、键盘输入及相机跟随均由该场景加载。
5. 使用 **W 加速、S 减速、A / D 转向**；点击右上角“返回主菜单”返回 StartMenu。

交互式编辑器的播放入口会设为 StartMenu，防止误运行 Untitled 空场景；此覆盖不作用于 Test Runner 和批处理。

## 打包与场景列表

在 **File → Build Settings → Scenes In Build** 检查以下场景已勾选：

| 顺序 | 场景 |
|---|---|
| 0 | `Assets/_Project/Scenes/StartMenu/StartMenu.unity` |
| 1 | `Assets/_Project/Scenes/GameScene/GameScene.unity` |

当前提交已经保存此配置。缺少或禁用任一场景会导致 `SceneManager` 无法加载目标场景；只有地图而没有菜单通常是打开/运行了错误的入口场景。

原场景 `Menu` / `Battle` 已分别重命名为 `StartMenu` / `GameScene`，原 `.meta` GUID 保留。其他分支若硬编码了旧场景名或旧路径，需要同步更新。
