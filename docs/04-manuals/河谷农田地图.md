# 河谷农田地图

采用用户选定的第 2 个地图方案，素材为项目现有的 Kenney Pixel Shmup 草地、海岸、河流、树木、农田、红顶建筑和土路。

## 运行

从开始界面点击开始游戏，或直接打开 `Assets/_Project/Scenes/GameScene/GameScene.unity` 并运行。编辑器默认从 StartMenu 开始，点击“开始游戏”进入地图；原来的开发用星点背景已替换为河谷农田地图。

地图保持现有战场尺寸 **400 × 300 世界单位**，包含 **800 × 600 个地形格**。16 × 16 地形格按 32 PPU 导入，每格为 0.5 世界单位；飞机尺寸及飞行参数保持原设置。出生点附近保留选定预览中的河谷、两岸道路和农田村落构图，远处延伸为同主题地形。

地形只作背景，不带碰撞体；飞机可以飞过河流、树林、建筑。AI、武器、地面目标和地形遮挡不属于本次接入。

## 内容与表现

| 文件 | 用途 |
|---|---|
| `Settings/Maps/RiverValley.asset` | 地图名称、尺寸、格子大小、布局与精灵调色板 |
| `Settings/Maps/RiverValleyTiles.bytes` | 静态布局，每字节索引一个地形精灵，从左至右、从上至下排列 |
| `Scripts/Gameplay/Config/BattleMapData.cs` | 只读地图配置类型 |
| `Scripts/Gameplay/World/BattleMapView.cs` | 镜头附近的 Tilemap 分块显示与回收 |
| `Editor/RiverValleyMapAuthoring.cs` | 构建该地图内容并由 Unity 保存 GameScene 场景 |

以上路径均相对于 `Assets/_Project/`。

地形共用现有的 `tiles_packed.png` 图集，切分为 120 个 16 × 16 精灵，采用 Point 过滤、无压缩、无 mipmap。背景排序为 -50，飞机保持在前方。地图按 32 × 32 格分块，仅加载镜头覆盖的区域，跨区时回收旧分块；不会为整张地图创建数十万个 GameObject。

地图数据不写入 Core，也不参与飞行模拟或威胁网格。新增同类地图可以创建新的 BattleMapData 资产并设置 BattleMapView 的 Map 引用。

## 重建与检查

Unity 菜单 **Tools → Dogfight Threat AI → 构建河谷农田地图** 会重新生成河谷布局、精灵切分及地图配置并保存 GameScene 场景。该操作会覆盖该地图的布局资产；保留手工修改前先保存副本。

EditMode 中的 `BattleMapTests` 检查全图布局、精灵引用、PPU、出生点、跨分块移动、四个战场角落的镜头覆盖、分块回收、排序与无碰撞体。现有 FlightModel 与 Grid2D 测试一同运行。

本机团结引擎 2022.3.62t16 验证：18 项 EditMode 测试全部通过；运行态实际飞行超过 45 世界单位，验证跨分块飞行、相机跟随、四角覆盖，以及 4:3 / 21:9 画幅。项目交付文件保留 Unity 2022.3 的场景格式与普通 GUID。
