# 自产素材（original）

用于存放自己产出或改造的素材，按类型分目录。

| 目录 | 内容 | 状态 |
|---|---|---|
| `sprites/` | 飞机、子弹、图标等位图 | 空 |
| `tiles/` | 地形与背景地块 | 空 |
| `ui/` | HUD、血条、雷达、按钮、准星 | 空 |
| `vfx/` | 粒子贴图、爆炸序列帧、尾焰 | 空 |
| `animations/` | 逐帧动画序列 | 空 |
| `audio/` | 音效与背景音乐 | 空 |
| `fonts/` | 位图字体与 TMP 字体源文件 | 空 |

## 约定

- 命名格式：`<类别>_<对象>_<编号>_<尺寸>.<扩展名>`，例如 `ship_player_01_32x32.png`。
- 像素密度应符合美术规范：PPU 32，Filter Mode 为 Point，Compression 为 None。
- 第三方素材统一放入 `art-source/third-party/<包名>/`，并在素材台账（文档待建）中登记授权信息。
